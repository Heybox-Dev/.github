# 高级功能

本章介绍 HeyBoxBot 的高级功能，包括身份验证、直播推流、音频控制和底层 HTTP API。

## 功能概览

| 模块                        | 功能                    |
|---------------------------|-----------------------|
| [OAuth 与账户](./oauth)      | 获取授权码、刷新 Token、获取账户信息 |
| [直播推流](./stream)          | 推送和停止直播流到频道           |
| [音频控制](./audio)           | 房间麦克风/扬声器静音           |
| [HTTP API 参考](./http-api) | 创建邀请码、文件上传等           |
