# 房间管理

HeyBoxBot 提供了完整的房间管理 API，包括房间操作、频道管理、身份组管理和表情管理。

## 功能概览

| 模块                 | 功能                             |
|--------------------|--------------------------------|
| [房间操作](./room-ops) | 获取房间信息、加入的房间列表、房间用户、设置昵称、踢人、禁言 |
| [频道管理](./channels) | 创建/删除频道、移动成员、频道静音、获取在线用户、频道设置  |
| [身份组管理](./roles)   | 创建/修改/删除身份组、授予/撤销身份组、权限管理      |
| [表情管理](./emojis)   | 获取房间表情、删除表情、修改表情名              |
